# Wireframe — livro.html (Leitura / Ambiente de Reflexões)
# Baixa fidelidade. Foco em tipografia e conforto visual. Página genérica

==========================================================
 DESKTOP (>= 1024px) — sidebar de conteúdo fixa à esquerda
==========================================================
┌──────────────────────────────────────────────────────────┐
│ 📖 Biblioteca de Reflexões                  [☰] (oculto)   │ <- navbar sticky
├───────────────┬──────────────────────────────────────────┤
│ CONTEÚDO      │  HERO (capa + título + lead)              │
│ (fixa)        │  [capa]   # Título PT                     │
│ ─ Navegação   │           resumo do livro...              │
│ 🏠 Início      │           [Começar a Ler]                │
│ 📖 Início Livro│ ─────────────────────────────────────── │
│ ─ Seções       │  SOBRE O LIVRO                           │
│ 📘 Sobre       │  metadados + citações (blockquotes)      │
│ 🧭 Ensinamentos│ ─────────────────────────────────────── │
│ 📚 Ideias      │  ENSINAMENTOS (cards numerados)          │
│ ⚖️ Verdades    │  [1] título  [2] título  [3] título      │
│ 💭 Reflexões   │ ─────────────────────────────────────── │
│                │  VERDADES E MITOS (grid truth/myth)       │
│                │  [Verdade] [Mito] [Verdade] ...          │
│                │  + textarea de reflexão                  │
│                │ ─────────────────────────────────────── │
│                │  MINHAS REFLEXÕES SALVAS                 │
│                │  (cards das reflexões do localStorage)   │
│                │                                           │
│                │  FOOTER                                   │
└───────────────┴──────────────────────────────────────────┘

  Largura de leitura: --max-width: 900px (conforto tipográfico).
  line-height: 1.7. Fonte heading serif (Georgia), body sans (Segoe UI).

==========================================================
 ELEMENTO: Bloco de Reflexão (persistido em localStorage)
==========================================================
┌──────────────────────────────────────────┐
│ 📝 Sua reflexão sobre Verdades e Mitos    │
│ ┌──────────────────────────────────────┐ │
│ │ textarea (placeholder)               │ │
│ └──────────────────────────────────────┘ │
│ [💾 Salvar Reflexão]  [🗑️ Limpar]         │
└──────────────────────────────────────────┘

  Ao salvar -> grava em localStorage['biblioteca_reflexoes'][step].
  Recarregar mantém o texto. Botão mostra "✅ Salvo!" por 1.5s.
